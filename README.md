4. Main menu - верхняя строка с пунктами File, Edit, View и т.д. Через неё выполняются все основные команды
Navigation bar - полоска под меню, показывает путь к текущему файлу
Project tool window - левая панель, где отображается дерево всех файлов и папок проекта
Editor - центральная область, где пишется код. Вкладки позволяют переключаться между открытыми файлами
Gutter - вертикальная полоска слева от редактора. На ней видны номера строк, точки останова для отладки и индикация изменений в Git
Tool windows-  это дополнительные панели (внизу и по бокам), которые открываются для конкретных задач: управление проектом, поиск, отладка, терминал и тп.
Status bar - самая нижняя строка. Показывает состояние проекта, кодировку файла, текущий интерпретатор Python и другую служебную информацию

Side Bar - основная боковая панель, которая показывает содержимое выбранного инструмента (например, список файлов, если выбран проводник)
Editor - центральная область для редактирования файлов
Status Bar - нижняя полоса с информацией о текущем файле 
Panel - нижняя область с терминалом, выводом отладки, списком проблем и консолью
