Контрольные вопросы:
1. Какое сочетание клавиш в PyCharm вызывает диалоговое окно для поиска любой команды, настройки, кода или файла?
Надо нажать Shift два раза подряд. Откроется окно, где можно найти что угодно. Ещё есть ctrl+shift+a для поиска конкретных команд
2. Где в PyCharm добавляют новые файлы, папки или пакеты?
В окне Project слева. Нажимаешь правой кнопкой мыши по папке, выбираешь New. Можно и через верхнее меню File -> New
3. Как называется основная организационная единица в PyCharm?
Проект. В нём хранятся все файлы и настройки для одного приложения
4. Правильный порядок действий для начала работы над новым проектом:
Сначала запускаем PyCharm, потом создаём новый проект, затем пишем код и запускаем программу
5. В чём преимущества IDE перед обычным блокнотом?
В IDE есть подсветка синтаксиса, поэтому код легче читать. Ещё она подсказывает названия функций и переменных, показывает ошибки сразу, можно ставить точки остановки и смотреть значения переменных во время выполнения; Есть встроенный терминал и много расширений на все случаи
